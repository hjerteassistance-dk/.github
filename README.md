# Hjerteassistance

Hjerteassistance is a Danish first-aid responder program. Trained Hjerteassistenter can be alerted through an app when a cardiac arrest is reported nearby and respond with a defibrillator.

Learn about the program, becoming a Hjerteassistent, sponsorships, and cardiac arrest facts at [hjerteassistance.dk](https://hjerteassistance.dk/).
